# Меню на неделю

Простой сайт для планирования меню на неделю для двоих. Сайт сам считает калории и белок
каждого человека и составляет список покупок.

## Из чего состоит

| Файл | Что это |
|---|---|
| `menu.json` | **Все данные**: люди и их нормы, продукты (ккал и БЖУ на 100 г), блюда. Менять нужно только этот файл. |
| `index.html` | Страница сайта. |
| `app.js` | Логика: расчёты, остатки, список покупок. |
| `style-ny.css` | Внешний вид (в стиле The New Yorker). Иллюстрация нарисована прямо в `index.html`. |

План недели хранится в браузере (localStorage) — отдельно на каждом телефоне и компьютере.
Если планируете с двух устройств, планы не синхронизируются.

## Как открыть на своём компьютере

Двойной щелчок по `index.html` **не сработает**: браузер не даёт странице прочитать `menu.json`
с диска. Нужно запустить маленький локальный сервер. В приложении «Терминал» перейдите в папку
проекта (проще всего напечатать `cd `, перетащить папку из Finder в окно Терминала и нажать Enter):

```bash
cd "$HOME/Documents/Документы:menu-planner"
```

```bash
python3 -m http.server 8765
```

И откройте в браузере http://localhost:8765. Остановить сервер — `Ctrl+C` в Терминале.

## Как добавить новое блюдо

1. Откройте `menu.json` (подойдёт любой текстовый редактор, например TextEdit в режиме
   «простой текст» или сразу на сайте GitHub — кнопка с карандашом ✏️).
2. Если в блюде есть **новый продукт**, которого ещё нет в разделе `"ingredients"`, добавьте его
   туда — ккал и БЖУ на 100 г (их можно посмотреть на упаковке):

   ```json
   "булгур сухой": {
     "kcal": 342, "protein": 12.3, "fat": 1.3, "carbs": 63.4,
     "pantry": false,
     "category": "Крупы, паста, хлеб"
   },
   ```

   - `"pantry": true` — продукт всегда есть дома (масло, специи): в список покупок не попадёт,
     но калории посчитаются.
   - `category` — отдел магазина; можно взять одно из уже существующих названий или придумать новое.
   - Для штучных продуктов добавьте `"unit": "шт", "grams_per_unit": 120` — тогда в списке
     покупок будет «3 шт», а не граммы.

3. В разделе `"dishes"` добавьте блюдо (поставьте запятую после предыдущего блюда):

   ```json
   {
     "id": "bulgur_chicken",
     "name": "Булгур с курицей",
     "meals": ["lunch", "dinner"],
     "preferred": "dinner",
     "default_portions": 2,
     "ingredients": [
       { "ingredient": "булгур сухой", "grams": 180, "who": "both" },
       { "ingredient": "куриное филе", "grams": 400, "who": "both" },
       { "ingredient": "хлеб (ломтик 30 г)", "grams": 60, "who": "maks" }
     ],
     "note": "Любой комментарий — покажется в рецепте."
   }
   ```

   - `id` — любое уникальное слово латиницей, без пробелов.
   - `meals` — куда можно поставить: `breakfast` (завтрак), `lunch` (обед), `dinner` (ужин).
   - `preferred` — где блюдо показывать первым в списке.
   - `default_portions` — 2 или 4.
   - `grams` — на **одну готовку = 2 порции** (обоим на один приём пищи).
   - `who`: `both` — общий продукт (делится по нормам: Настюшка ~36%, Макс ~64%),
     `nastya` или `maks` — только для этого человека.
   - `"optional": true` у ингредиента — в приложении появится галочка «добавить …».
   - Название продукта в `ingredient` должно **точь-в-точь** совпадать с названием в разделе
     `"ingredients"`.
   - Поля `per_portion` писать не обязательно: сайт сам считает КБЖУ из ингредиентов.

4. Сохраните файл. Если сайт после этого показывает ошибку «Не получилось загрузить menu.json» —
   скорее всего, пропущена или лишняя запятая. Проверить файл можно на https://jsonlint.com
   (вставьте туда текст и нажмите Validate).

Норму калорий человека меняют в разделе `"people"` → `"kcal_target"`, доли приёмов пищи — в
`"meal_split"`.

## Как обновить сайт в интернете

На GitHub откройте свой репозиторий → файл `menu.json` → ✏️ (Edit) → внесите правку →
**Commit changes**. Через 1–2 минуты сайт обновится (на телефоне иногда нужно обновить страницу).
